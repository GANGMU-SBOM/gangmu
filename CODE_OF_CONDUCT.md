# 行为准则 · Code of Conduct

本项目采用 [Contributor Covenant 2.1](https://www.contributor-covenant.org/zh-cn/version/2/1/code_of_conduct/)
作为行为准则。This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

简而言之：对事不对人；欢迎不同背景、不同经验水平的贡献者；不接受骚扰、人身攻击和泄露他人隐私。
In short: critique work, not people; welcome contributors of every background and
experience level; harassment, personal attacks and doxxing are not tolerated.

适用范围包括 issue、pull request、讨论区以及以项目名义进行的一切交流。
This applies to issues, pull requests, discussions and any communication on the
project's behalf.
